---
description: Thực hiện một Milestone theo roadmap
---
1. Đọc `docs/07-ROADMAP.md`, xác định Milestone kế tiếp chưa xong.
2. Lập kế hoạch ngắn (file sẽ tạo/sửa, test sẽ viết). Chờ duyệt nếu thay đổi kiến trúc.
3. Viết test trước cho phần logic; code; chạy `npm run check`.
4. Với UI: chạy dev server, chụp ảnh mobile 390px + desktop 1440px, light + dark.
5. Cập nhật `docs/DECISIONS.md` nếu có quyết định mới.
6. Báo cáo: đã làm, ảnh chụp, việc dở, rủi ro. Dừng chờ "tiếp".
